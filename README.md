# یادەوەر (Yadawar)

ئەپێکی Android بە زمانی کوردی (سۆرانی) و دیزاینی تاریک/مۆر.

## تایبەتمەندییەکان
- زیادکردنی بیرخەرەوە بە کات و نامە
- نۆتفیکەیشن بە Android AlarmManager
- پاشەکەوتی ناوخۆیی بە SharedPreferences
- دووبارە دانانەوەی بیرخەرەوەکان دوای Restart
- چالاک/ناچالاککردن و سڕینەوە
- دەنگی ئاگادارکردنەوە بە کۆنترۆڵی Channel

## دروستکردنی APK لە GitHub
1. ئەم پڕۆژەیە وەک Repository ـێکی نوێ لە GitHub بار بکە.
2. Actions ـەکان لە Repository settings ئەگەر ناچالاکن چالاکیان بکە.
3. لە Actions، `Build Yadawar APK` هەڵبژێرە و `Run workflow` بکە.
4. دوای تەواوبوونی Build، Artifact ـی `yadawar-debug-apk` دابەزێنە.
5. فایلە ZIP ـەکە بکەرەوە و `app-debug.apk` دابەزێنە.

## ڕێکخستنی مۆبایل
لە یەکەم جاردا ڕێگە بە Notifications بدە. لە Android 12+ ڕێگەی Exact Alarms چالاک بکە.
لە Realme UI، بۆ باشترین جێگیری، بۆ ئەم ئەپە Background activity / Auto-launch ڕێگەپێبدە و battery optimization ـی سنووردارکەر لاببە.

## گرنگ
ئەمە وەشانی بنەڕەتییە و APK ـەکە Debug ـە، نەک بڵاوکراوەی Play Store. پێش بەکارهێنانی ڕۆژانە، لە مۆبایلەکەتدا نۆتفیکەیشن، ڕێگەی کاتژمێری ورد، و دووبارە هەڵستانەوەی مۆبایل تاقی بکەرەوە.
